# Mar La Criolla — sito (bozza)

Eleventy 3. `npm install` → `npm start` (locale) / `npm run build` → `_site`.
Netlify: build `npm run build`, publish `_site` (netlify.toml).

Da modificare senza toccare il codice:
- `src/_data/site.json` — numero WhatsApp, Instagram, posti fondatori (`founders.available`).
- `src/_data/prezzi.json` — prezzi in presenza e online.
- `src/_data/stili.json` — stili e descrizioni.
- `src/blog/*.md` — articoli del blog.
